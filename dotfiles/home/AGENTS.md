# AERISOS system map — persistent agent reference

Standing knowledge so the agent can answer questions about data seen in the AERIS
dashboard ("when I open AERIS and open code") without re-discovering it each session.
Update this file whenever a data location, threshold or pipeline changes.

## Status board pipeline (what the user sees in the dashboard/TUI)
- Generator: `/home/h/aerisos/status/aeris-status` (Python), run by
  `~/.config/systemd`-side `aeris-status.service` + `.timer`
  (unit files in `/home/h/aerisos/status/aeris-status.service|.timer`).
- Output: `/var/lib/aeris/status.json` (public) and `private.json` (per-source caches:
  `air-cache.json`, `gpsjam-cache.json`, `net-cache.json`, `news-cache.json`,
  `swpc-cache.json`, `tle-cache.json`, `ioda-cache.json`, `lock.tsv`).
- Display: OpenCode plugin `~/.config/opencode/plugins/aeris-board/tui.tsx`
  (reads `s().air.gnss` etc. from the status JSON via Ollama context card).
- Values shown inverted (black on white) when notable; e.g. GNSS jammed, emergency
  squawk, ISS/Tiangong overhead, G1+ storm, internet outage. `STALE` label = failed refresh.

## GNSS alert semantics (air.gnss)
- Metric: among aircraft in the 50 km adsb.fi circle **above 1,000 ft** (surface targets
  excluded — tower beacons and ground vehicles report NACp 0 routinely), count `nac_p < 8`.
  `OK` = fewer than 2, `LOW` = 2 or more, `JAMMED` = 3 or more and >10% share.
- The alert list (`status.json` `alerts`) only fires on the literal string `JAMMED …`
  and emergency squawks etc.; `LOW x/y` is an indicator only — it does not invert the card
  and does not alert. Baseline noise here is the Valencia VFR training fleet (Airpull
  PA-28s, EC-GEG etc.) whose uncertified GPS reads NACp 0 with no interference present.
- To inspect now: `cd /var/lib/aeris && python3 -c "import json; s=json.load(open('status.json'))`
  and read `air-cache.json` / `gpsjam-cache.json`.

## Dock (since 2026-10-22)
- Bottom pill dock = quickshell 0.3.2 (replaces GTK3 nwg-dock-hyprland, which
  could not render fractional-scale sharp at 1.6x).
- Config: `~/.config/quickshell/aeris-dock/shell.qml` (running-apps pill, icons
  via the Mono icon theme, hidden by sliding below the bottom edge).
- Driver: `~/.local/bin/dock-autohide` now launches quickshell and drives
  show/hide through IPC (`qs ipc -p <shell.qml> call dock reveal|conceal`;
  note `show`/`hide` are reserved `qs ipc` subcommands). Backed up as
  `dock-autohide.nwg.bak`. Launched at login from `~/.config/hypr/hyprland.lua`.
- A parallel Claude Code session may run `~/quickshell-test/shell.qml` (test bar).

## Other standing infrastructure
- Watchlist (news topics, feeds, real-time collection): manage with
  `/home/h/.local/bin/aeris-watch`; findings in `/home/h/.local/share/aeris/watchlist.json`.
  Current items (since 2026-10-21): cfsn-helsing (de-DE), palantir (en+de), anduril (en+de),
  chapsvision (fr+en), helsing (en+de). Since 2026-10-22 the company items (palantir, anduril,
  helsing, chapsvision) watch the plain company names (broadened at the principal's request),
  not just Europe/NATO angles; `cfsn-helsing` stays a focused contract question.
- Watchlist findings history: `ack` moves findings into each item's `archive` (last 500) in
  watchlist.json instead of discarding them; `aeris-watch log [NAME]` prints all of it, and
  every state change rewrites `~/.local/share/aeris/watch.html`, a readable page with per-item
  notes and full article history (unacknowledged marked with a star). Checked hourly
  (aeris-watch.timer).
- Chats/commands: `/watch` (watchlist), `/brief` (situation brief incl. GNSS interference),
  `/inbox` (OpenCode) and `/watch-inbox` (Claude Code): the watchlist as a numbered inbox
  via `~/.local/bin/aeris-inbox`, "open N" for detail, ack per topic.
- Defence-map ontologies: `~/maps`, query with `aeris-onto`.
