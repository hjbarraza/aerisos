Research: $ARGUMENTS

Method:
1. Restate the question and break it into the specific sub-questions that must be answered. State any assumption you make about scope.
2. Collect: use web search and web fetch. Prefer primary sources (official documents, datasets, filings, original reporting) over aggregators. Seek at least two independent sources for every key claim.
3. Corroborate: note where sources agree, conflict, or repeat each other (circular reporting is one source, not two).
4. Grade each source: reliability A–F, credibility 1–6.
5. Report in the standard format: BLUF, key judgments with confidence, evidence with links, dates and grades, gaps and next collection.

Never present a claim you could not source as fact. If search fails or results are thin, say so plainly.
